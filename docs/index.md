# 💯 100 Days of ML

Welcome to the **100 Days of Machine Learning and Deep Learning** challenge! 🚀  
This repository documents a daily journey of learning and building with ML (Machine Learning) and DL (Deep Learning). Whether you're a beginner or brushing up your skills, this challenge is designed to help you stay consistent and grow.

---

## 📌 Goal

To build a strong, practical understanding of key ML/DL concepts and techniques by committing to daily learning and coding for 100 days.

---


Each day includes:
- ✅ A focused concept or algorithm
- 📘 Explanation/Notes
- 🧪 Code implementation
- 📎 References to additional reading

---

## 🧠 Topics Covered

- Supervised Learning
  - [Linear Regression](./tutorials/Day-01/index.md)
  - Logistic Regression
  - Decision Trees
  - SVMs
- Unsupervised Learning
  - K-Means
  - PCA
- Neural Networks
  - Feedforward NN
  - Backpropagation
  - CNNs
  - RNNs & LSTMs
- Deep Learning Frameworks (PyTorch, TensorFlow)
- GANs and VAEs
- Transformers & Attention Mechanisms
- Model Optimization
- Model Deployment
